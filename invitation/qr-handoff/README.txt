QR CODES — Keerthy & Abhijith
=============================

Two codes. They are NOT interchangeable.

  qr-all-events    Guests invited to all three celebrations
                   (Sangeet, the wedding, the reception)

  qr-wedding-day   Everyone else — the general invitation


Each comes as .svg and .png.

  .svg   Vector. Scale it to any size with no loss. Use this one.
  .png   ~1960px, in case the SVG is inconvenient. Do not scale it up.

Both are pure black on white so you can place them on any background.


FOUR RULES
----------

1. MINIMUM SIZE 25mm / 1 inch square, finished. The all-events code has more
   modules and so smaller ones, and is the one that fails first if reduced.

2. KEEP THE WHITE BORDER. The empty margin around the code is not padding you
   can trim — scanners lock onto it. It is already built into both files at
   the correct width.

3. DARK ON LIGHT ONLY. Do not invert them, do not print them gold on plum, do
   not tint them. You may recolour the dark modules to a very dark colour if
   you must, but keep strong contrast against a light background.

4. DO NOT REDRAW, SMOOTH OR RE-TRACE THEM. If you need a different colour or
   size, use the SVG.


BEFORE THE FULL RUN
-------------------
Scan both codes off a PAPER PROOF with an ordinary phone. Not off a screen.
They point at two different pages, so test them separately.
